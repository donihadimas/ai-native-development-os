# Release: 0.7.2 (Integration Guidance & Graphify Extract Patch)

## Scope

- Included: Fix Graphify CLI command invocation in `aios map` from `graphify ingest` to `graphify extract . --code-only`, provide clear manual and automated installation guides when external tools are missing in `aios integration add`, enhance Graphify integration documentation with productive inspection commands (`query`, `explain`, `affected`), add `graphify-out/` to `.gitignore`, and add comprehensive integration tests.
- Excluded: Schema changes or breaking CLI API modifications.

## User-Visible Changes

- **Fixed Graphify Codebase Extraction**: `aios map` now executes the correct `graphify extract . --code-only` command to extract AST relationships and generate knowledge graph assets locally without requiring an external LLM API key.
- **Enhanced Missing Integration Guidance**: Running `aios integration add <name>` when the external tool is not detected now prints:
  - Step-by-step manual installation commands and platform-specific notes (such as handling Debian/Ubuntu Linux PEP 668 for Python packages).
  - Clear guidance on running automatic installation with `aios integration add <name> --install --yes`.
- **Extended Graphify Rules & Capabilities**: Updated `.aios/integrations/graphify.md` with guidelines on running `graphify query`, `graphify explain`, `graphify affected`, and `graphify extract`.
- **Repository Hygiene**: Local Graphify artifacts directory `graphify-out/` is automatically ignored in `.gitignore`.

## Developer-Visible Changes

- **CLI Fix in `commandMap`**: Replaced outdated `graphify ingest` invocation with `graphify extract . --code-only` in `cli/src/index.ts`.
- **Enhanced `commandIntegrationAdd` Output**: Added structured tips and installation notes when `detection.detected` is false.
- **Updated Test Suite**: Added dedicated tests in `cli/test/commands.test.ts` for verifying manual install guides and auto-install suggestions when external tools are missing.

## Validation Evidence

- **Tests**: 108 passing, 0 failing across all unit and command integration tests (`npm --prefix cli test`).
- **Live Verification**:
