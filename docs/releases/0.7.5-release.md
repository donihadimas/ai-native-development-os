# Release: 0.7.5 (AIOS Core Directives & Templates Standardization)

## Scope

- Included: Cleanup of redundant skeleton & starter `docs/context/` assets (`context-map.md`, `development-start.md`), standardization of `## Status`, `## Created Datetime`, and `## Finish Datetime` in tasking and plan templates, V2.x workflow refactoring, and removal of stale `done/` archiving rules across skills, workflows, and references.
- Excluded: Breaking CLI flags.

## User-Visible Changes

- **Standardized Task & Plan Templates**: All created task and plan templates (`task.template.md`, `implementation-plan.template.md`, `test-plan.template.md`, `migration-plan.template.md`) now include standardized `## Status`, `## Created Datetime`, and `## Finish Datetime` sections.
- **Lean Project Skeletons & Starters**: Creating new projects or adopting AIOS with `aios init` or `aios starter` generates clean, lightweight documentation without redundant `docs/context/` boilerplate or outdated `done/` archiving directives.

## Developer-Visible Changes

- **Skeleton & Starter Pruning**: Removed `docs/context/context-map.md` and `docs/context/development-start.md` from `project-skeleton/` and all 7 starters (`flutter-mobile`, `fullstack-saas`, `laravel-api`, `nestjs-api`, `nextjs-web`, `node-api`, `supabase-app`).
- **Workflow Refactoring**: Refactored all 10 workflow files (`api-contract`, `bugfix`, `database-migration`, `new-feature`, `new-project`, `refactor`, `release`, `review`, `security-review`, `ui-design`) to use 4 core skills (`spec`, `arch`, `task`, `verify`) + domain skills, in-place `Status: Done` updates, and dynamic skill invocation without mandatory router preloads.
- **Skill & Reference Alignment**: Updated `release-management` and `database-migration` skills as well as `artifact-lifecycle.md` and `workflow-modes.md` references to enforce in-place task state management.
- **CLI Validator Update**: Removed legacy `context/development-start.md` from `REQUIRED_DOCS_PATHS` in `cli/src/core.ts` and updated CLI test assertions.

## Validation Evidence

- **Tests**: All 110 unit and integration tests passing (`npm --prefix cli test`).
- **Build & Asset Sync**: TypeScript build and asset sync succeed (`npm --prefix cli run build`).
