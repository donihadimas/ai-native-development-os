# Release: 0.7.4 (Sidecar Animated Progress Spinner & EPIPE Fix Patch)

## Scope

- Included: Real-time non-blocking sidecar process braille spinner animation (`⠋ ⠙ ⠹`) for `aios verify` and `aios map`, `worker.stdin` EPIPE error handling, 50ms progress update throttling, and progress filtering on large codebases.
- Excluded: Schema modifications or breaking API changes.

## User-Visible Changes

- **Real-Time Animated Progress Spinner**: Running `aios verify` or `aios map` in an interactive terminal displays a live braille spinner (`⠋ ⠙ ⠹`) that rotates smoothly at 20 FPS during execution.
- **Large Repository Progress Stability**: Commands like `aios map` running on large repositories (e.g. 4,000+ files) run smoothly without unhandled stream exceptions (`EPIPE`) or terminal crashes.

## Developer-Visible Changes

- **Sidecar Worker Spinner Engine (`cli/src/core.ts`)**:
  - Implemented `startSpinner()` spawning an independent Node.js child process worker for rendering terminal spinner frames.
  - Attached `.on("error")` handlers to `worker` and `worker.stdin` to swallow `EPIPE` signals when worker processes are killed.
  - Added 50ms time throttling to `spinner.update()` to prevent pipe buffer overflows.
- **Progress Callback Filtering (`cli/src/index.ts`)**:
  - Filtered `generateRepoMap` callback updates in `commandMap` to fire every 10 files (or first file), reducing pipe payload volume on large codebases.
