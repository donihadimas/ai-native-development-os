# Release: 0.7.0 (V2.x Architecture & Integrations)

## Scope

- Included: Isolated task worktrees (`aios worktree`), deterministic test verification (`aios verify`), task graph dependency rendering (`aios tasks`), AST repository mapping (`aios map` updates), telemetry logging (`aios stats`), multi-tool configuration exporter (`aios export`), optional Graphify integration, forced clean updates (`aios update --clean`), and skill consolidation (streamlined into 5 core skills).
- Excluded: Production deployment configurations.

## User-Visible Changes

- **Task Isolation via Git Worktrees**: Run tasks in dedicated git worktrees using `aios worktree start <task-id>` and `aios worktree finish <task-id>`.
- **Deterministic Verification**: Verify code changes deterministically using `aios verify`, which auto-detects language test runners.
- **Dependency Visualization**: Preview task workflows and identify dependency cycles using `aios tasks`.
- **Auto-Rollback**: Automatic circuit breaking and rollback stashing using `aios rollback` when agent limits are exceeded.
- **Codebase AST Indexer**: Upgraded repository mapping to construct detailed symbol index trees in `repo-map.json` using `aios map`.
- **Multi-Tool Exporter**: Export AIOS rules using `aios export` targeting Cursor, Claude, Cline, Windsurf, and Copilot.
- **Graphify Integration**: Option to link Graphify codebase knowledge graph as a local or user-wide integration.
- **Forced Clean Update**: Use `aios update --clean` to force-overwrite core templates and prune deprecated skills/assets while protecting user tasks, plans, and doc folders.

## Developer-Visible Changes

- Consolidated core native agent skills under `.agents/skills/` into 5 high-impact modules: `spec`, `arch`, `task`, `verify`, and `release-management`.
- Trimmed and optimized generated `AGENTS.md` and starters.
- Added agent telemetry telemetry instrumentation logging run durations, token estimation, and task transitions in `.aios/telemetry/`.
