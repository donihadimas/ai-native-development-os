# Release: 0.7.3 (Managed Section Update, Integration Rule Sync & Kotlin Support Patch)

## Scope

- Included: Managed section replacement (`<!-- AIOS:BEGIN -->` to `<!-- AIOS:END -->`) during `aios update`, automatic integration rule syncing to `AGENTS.md` / `CLAUDE.md`, external skill preservation during `update --clean`, Kotlin/Gradle test runner detection and AST indexing, live progress logging during `aios verify` and `aios map`, Graphify in guided setup, and interactive multiselect export prompt.
- Excluded: Breaking CLI API changes or structural schema breaking modifications.

## User-Visible Changes

- **Managed Section Updates**: Running `aios update` now cleanly overwrites content between `<!-- AIOS:BEGIN -->` and `<!-- AIOS:END -->` in `AGENTS.md` and `CLAUDE.md` instead of appending duplicate sections or skipping updates.
- **Automatic Integration Rules Injection**: Enabling integrations via `aios integration add` or guided setup flows (`adopt`, `init`, `create`) automatically syncs their rule content into `AGENTS.md` and `CLAUDE.md`.
- **External Integration Skill Preservation**: Running `aios update --clean` no longer purges enabled external skills (`caveman`, `ponytail`, `rtk`, `graphify`) from `.aios/skills/`.
- **Kotlin & Gradle Support**:
  - `aios verify` automatically detects Gradle projects (`build.gradle`, `build.gradle.kts`, `gradlew`, `gradlew.bat`).
  - `aios map` parses Kotlin and Kotlin Script files (`.kt`, `.kts`) and extracts classes, interfaces, data classes, objects, and functions into `.aios/repo-map.json`.
- **CLI Progress Logging & UX**:
  - `aios verify` displays live progress messages before executing test suites to prevent blank screens.
  - `aios map` displays progress indexing markers (e.g. `[10] Indexing src/...`).
  - `aios export` (when executed without `--target` or from the interactive `aios` menu) launches an interactive multiselect checkbox prompt allowing users to choose any combination of AI agents (Cursor, Claude, Cline, Windsurf, Copilot), supporting single or multi-target exports (e.g. `--target cursor,claude`).
  - Graphify is included in the guided integration selection prompt.

## Developer-Visible Changes

- **Core Module Updates (`cli/src/core.ts`)**:
  - Added `updateAiosManagedSection` for replacing managed sections in agent documentation.
  - Passed `preservedSkills` set to `cleanExtraEntries` to preserve active external integration skills.
- **Verification Engine Updates (`cli/src/verify.ts`)**:
  - Extended `detectTestRunner` to detect Gradle/Kotlin builds.
  - Added `onProgress` callback support to `runVerification`.
- **AST Indexer Updates (`cli/src/indexer.ts`)**:
  - Added `.kt` and `.kts` file extensions to `SUPPORTED_EXTENSIONS`.
  - Added regex symbol parsing for Kotlin syntax in `parseSymbols`.
